# Vidéos de maquette et showreels

Exemples à regarder **image par image** : noter durée des plans, transitions, place du texte, musique. Pour chaque vidéo marquante, créer une fiche avec [[Fiche référence]] et, si on garde une copie pour étude interne, la ranger dans `medias/videos/` (voir `medias/README.md`).

## Vidéos de maquette (mockups animés)

- **Rotato — 14 idées et exemples de vidéos mockup** : <https://rotato.app/blog/mockup-video-examples>
  Panorama de mises en scène (3D, appareils, défilement) avec modèles. Point de départ pour le vocabulaire de plans.
- **Rotato — guide des vidéos mockup** : <https://rotato.app/blog/guide-to-video-mockups>
- **Rotato — passer d'un écran d'ordinateur à un téléphone posé sur le bureau** : <https://rotato.app/blog/monitor-to-phone-transition>
  ➜ Transition utile pour montrer **desktop puis mobile** du même site. `#transition` `#a-reproduire`
- **Jitter — modèles « devices »** : <https://jitter.video/templates/devices/>
  Transitions d'écran, appuis de boutons, défilements : bonne bibliothèque de micro-mouvements d'UI. `#device-mockup`
- **Moonb — 12 outils pour mockups animés** : <https://www.moonb.io/blog/animated-mockups> (panorama d'outils, avec exemples).

## Grille d'analyse rapide (à remplir pour chaque vidéo)

| Champ | Exemple |
|---|---|
| Durée totale / nombre de plans | 22 s / 11 plans |
| Plan d'ouverture (accroche) | Zoom arrière depuis le mot-clé du hero |
| Famille de transitions | Rideaux verticaux + match-cut sur la couleur |
| Mockup d'appareil ? | 2 plans sur 11 |
| Texte ajouté | 3 cartons, 4 mots max |
| Musique / sound design | Électro 118 BPM, coupes sur les temps |
| À reprendre | Le match-cut sur la couleur de marque |
