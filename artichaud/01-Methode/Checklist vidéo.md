# Checklist vidéo (avant publication)

## Contenu
- [ ] Le premier plan se comprend muet, en moins d'une seconde.
- [ ] Chaque plan montre une seule idée.
- [ ] Aucun lorem ipsum ni donnée fictive non assumée à l'écran (ou alors floutée / hors champ).
- [ ] Le nom du client et le nom du studio sont corrects (orthographe, logo à jour).
- [ ] Le numéro de téléphone / l'URL affichés sont les bons.

## Image
- [ ] Rendu à cadence constante (30 ou 60 i/s), aucune saccade ni image dupliquée.
- [ ] Aucun élément clé hors des zones de sécurité ([[Formats réseaux sociaux]]).
- [ ] Polices de la marque bien chargées (pas de police de secours).
- [ ] Pas de texte qui disparaît avant d'être lisible (≈ 0,3 s/mot + 1 s).
- [ ] Les couleurs correspondent à la maquette (pas de dérive de gamma à l'export).

## Son
- [ ] Musique sous licence compatible usage commercial / réseaux, référence notée dans la fiche projet.
- [ ] Niveau homogène, pas de saturation ; la vidéo reste compréhensible sans le son.

## Livraison
- [ ] Master haute qualité archivé dans `05-Projets/<projet>/`.
- [ ] Une version par format (9:16, 4:5, 16:9…) exportée depuis le master.
- [ ] Image de couverture (cover Reels) choisie.
- [ ] Accord du client pour diffuser son site dans la communication du studio.

## Après publication
- [ ] Noter dans la fiche projet : ce qui a marché, ce qu'on referait autrement, les statistiques à J+7.
